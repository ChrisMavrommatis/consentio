# memory

Durable "why" with no home in a design record or a plan. **One fact per file.**

Add a fact here only when no other layer fits: not behaviour a user needs (that is `website/`), not reasoning
about the design (that is `../design/`), not work outstanding (that is `../plans/`).

**The common reason a fact belongs here: a plan that records it is going to be deleted.** Every plan is
deleted once its work lands, and anything true and useful in it dies with it. Move that out before it goes.

Delete a memory when its fact moves into a design record, or turns out to be wrong.
